# Input/Output Samples

This folder provides a minimal, self-contained input/output example to help you quickly understand what QSPLIT consumes as **target code** and what it produces as **generated dummy components**.

## What this sample demonstrates

- **Input**: an example target component file (`StateEncoder6Q.py`) for a 6-qubit setting.
- **Output**: example generated dummy variants for missing QNN components (Encoder / PQC / Measurement), saved as Python modules.

This sample is intended for **workflow verification and format reference**, not for reporting model performance.

## Input

### `Input/StateEncoder6Q.py`
A minimal example of a target State Encoder implementation.
- Assumes `n_qubits = 6`
- Uses `torch` / `torchquantum`
- Implements a `forward()` that returns quantum states (example format used by QSPLIT)

You can replace this file with your own target component, as long as it follows the interface expected by QSPLIT.

## Output

### `Output/*Dummy{0,1,2}.py`
Example dummy variants generated by QSPLIT.
- The suffix `{0,1,2}` indicates different **template variants / configurations** produced under the same hyperparameter setting (e.g., `n_qubits=6`).
- Files are provided for:
  - `ENCODER6QDummy*`: encoder variants
  - `PQC6QDummy*`: PQC variants
  - `MEA6QDummy*`: measurement variants (often includes a small classifier head)

These files are included to show the **exact code format** and help users validate that dummy generation works as intended.

## How to use this sample

### Option A) Web UI
1. Open QSPLIT Web UI.
2. Upload or paste `Input/StateEncoder6Q.py` as the target component.
3. Select which components are missing (or which parts you want QSPLIT to auto-complete).
4. Set hyperparameters (e.g., `n_qubits=6`).
5. Run dummy generation / split learning execution.
6. Compare the generated files with the examples in `Output/`.

### Option B) Python backend/API (reference)
If you run QSPLIT via the backend runner, pass the input file path as a target component and confirm that dummy files are generated and the run completes.

Note: the exact function/endpoint name may differ depending on your installation. Please follow the main repository README for the authoritative run command.

## Notes

- If your target code uses additional dependencies or a different output tensor format, ensure it matches QSPLIT’s compatibility requirements (e.g., qubit count alignment, shape consistency).
- These examples are intentionally lightweight to support quick sanity checks and early-stage log inspection.
